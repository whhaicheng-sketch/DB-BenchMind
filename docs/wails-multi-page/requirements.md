## 背景

### 当前状态

当前 Wails 版本已完成 Phase 1-5 的开发，实现了：
- 连接管理（缩放在左侧边栏）
- 模板管理（缩放在左侧边栏）
- Benchmark 执行（Prepare/Run/Stop/Cleanup）
- 实时监控图表（TPM/TPS/CPU/Disk IO/Disk Space）
- 实时日志输出

### 当前问题

当前界面采用**单页面布局**，所有功能都挤在一个页面上：

```
┌─────────────────────────────────────────────────────────────┐
│  Sidebar (300px)          │    MainContent                 │
│ ┌────────────────────┐    │    ┌─────────────────────┐     │
│ │ Connection 列表    │    │    │ Real-time Monitor   │     │
│ │ Template 列表      │    │    │ ├─ TPM Chart        │     │
│ │ Parameters 配置    │    │    │ ├─ TPS Chart        │     │
│ │ [Prepare][Run]     │    │    │ ├─ CPU Chart        │     │
│ │ [Stop] [Cleanup]   │    │    │ ├─ Disk IO Chart    │     │
│ │ Status 状态        │    │    │ └─ Disk Space Chart │     │
│ │ Log Panel 日志     │    │    │                     │     │
│ └────────────────────┘    │    └─────────────────────┘     │
└─────────────────────────────────────────────────────────────┘
```

**存在的问题**：
1. **功能展示不清晰**：Connection 和 Template 管理功能被压缩在边栏中
2. **缺少独立页面**：History、Comparison、Report、Settings 功能完全缺失
3. **用户体验差**：与原来 Fyne 版本的 7 个独立标签页相比，功能不完整
4. **可扩展性差**：单页面布局难以添加更多功能

### 参考：原 Fyne 版本结构

原 Fyne 版本采用**多标签页导航**：

```
┌─────────────────────────────────────────────────────────────┐
│ [Connections] [Templates] [Tasks&Monitor] [History]         │
│ [Comparison] [Reports] [Settings]                           │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│                    当前选中的页面内容                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 问题陈述

**核心问题**：当前 Wails 界面缺少多页面导航结构，导致功能展示不清晰、部分功能缺失。

**影响范围**：
- 用户无法像 Fyne 版本一样管理连接（独立页面）
- 用户无法像 Fyne 版本一样管理模板（独立页面）
- 用户无法查看历史记录
- 用户无法进行结果比对
- 用户无法生成报告
- 用户无法配置系统设置

## 用户场景

### UC1：管理数据库连接

**角色**：DBA

**前置条件**：无

**主流程**：
1. WHEN 用户点击左侧导航栏的 "Connections" 菜单项
2. THE SYSTEM SHALL 在右侧主内容区显示 Connections 页面
3. THE SYSTEM SHALL 显示已保存的连接列表
4. WHEN 用户点击 "New Connection" 按钮
5. THE SYSTEM SHALL 显示连接创建表单
6. WHEN 用户填写表单并点击 "Save"
7. THE SYSTEM SHALL 保存连接并刷新列表
8. WHEN 用户点击某连接的 "Test" 按钮
9. THE SYSTEM SHALL 测试连接并显示结果

### UC2：管理 Benchmark 模板

**角色**：DBA

**前置条件**：无

**主流程**：
1. WHEN 用户点击左侧导航栏的 "Templates" 菜单项
2. THE SYSTEM SHALL 在右侧主内容区显示 Templates 页面
3. THE SYSTEM SHALL 显示可用的模板列表
4. WHEN 用户选择某个模板
5. THE SYSTEM SHALL 显示模板详情和参数说明

### UC3：执行 Benchmark 并监控

**角色**：DBA

**前置条件**：
- 已创建数据库连接
- 已了解模板参数

**主流程**：
1. WHEN 用户点击左侧导航栏的 "Tasks & Monitor" 菜单项
2. THE SYSTEM SHALL 在右侧主内容区显示 Tasks & Monitor 页面
3. WHEN 用户选择连接、模板并设置参数
4. AND 用户点击 "Run" 按钮
5. THE SYSTEM SHALL 开始执行 Benchmark
6. THE SYSTEM SHALL 实时显示 TPM/TPS 图表
7. THE SYSTEM SHALL 实时显示系统监控图表
8. THE SYSTEM SHALL 实时显示执行日志
9. WHEN Benchmark 完成
10. THE SYSTEM SHALL 显示最终结果

### UC4：查看历史记录

**角色**：DBA

**前置条件**：已有 Benchmark 运行历史

**主流程**：
1. WHEN 用户点击左侧导航栏的 "History" 菜单项
2. THE SYSTEM SHALL 在右侧主内容区显示 History 页面
3. THE SYSTEM SHALL 显示历史运行列表
4. WHEN 用户点击某条记录的 "Details" 按钮
5. THE SYSTEM SHALL 显示详细运行结果
6. WHEN 用户点击 "Export" 按钮
7. THE SYSTEM SHALL 导出该记录的报告

### UC5：对比运行结果

**角色**：DBA

**前置条件**：至少有 2 条历史记录

**主流程**：
1. WHEN 用户点击左侧导航栏的 "Comparison" 菜单项
2. THE SYSTEM SHALL 在右侧主内容区显示 Comparison 页面
3. WHEN 用户选择多条历史记录
4. AND 用户点击 "Compare" 按钮
5. THE SYSTEM SHALL 生成对比报告
6. THE SYSTEM SHALL 显示性能指标对比

### UC6：生成报告

**角色**：DBA

**前置条件**：已有 Benchmark 运行历史

**主流程**：
1. WHEN 用户点击左侧导航栏的 "Reports" 菜单项
2. THE SYSTEM SHALL 在右侧主内容区显示 Reports 页面
3. WHEN 用户选择运行记录和报告格式
4. AND 用户点击 "Generate" 按钮
5. THE SYSTEM SHALL 生成指定格式的报告

### UC7：配置系统设置

**角色**：DBA

**前置条件**：无

**主流程**：
1. WHEN 用户点击左侧导航栏的 "Settings" 菜单项
2. THE SYSTEM SHALL 在右侧主内容区显示 Settings 页面
3. WHEN 用户修改工具路径或超时设置
4. AND 用户点击 "Save" 按钮
5. THE SYSTEM SHALL 保存设置

**布局原则**：
1. **左侧垂直导航**：固定宽度（200px），包含导航菜单
2. **右侧主内容区**：自适应宽度，显示当前页面内容
3. **顶部标题栏**：显示当前页面标题（可选）
